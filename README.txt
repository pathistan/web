1. Descomprime la carpeta.
2. Abre index.html con Chrome, Edge o Firefox.
3. Para administrar, selecciona "Administrar sitio" al pie de la página o abre admin.html.
4. Acceso demostrativo: usuario admin / contraseña Cambiar123!
5. Fotografía: ya se incluye la fotografía profesional en assets/foto-marcos.jpg. Para sustituirla, conserva ese nombre de archivo.

IMPORTANTE:
- El contenido de experiencia incluido es un borrador basado en datos compartidos anteriormente; revisa y confirma empresas, periodos y funciones antes de publicarlo.
- El correo de contacto es un marcador de posición. Cambia contacto@tudominio.com por tu correo real.
- Los cambios de administración se guardan en localStorage del navegador y dispositivo. No se sincronizan entre dispositivos ni constituyen seguridad real.
- La contraseña de demostración está escrita en JavaScript y NO es segura para un sitio público. Para publicar con administración real, se requiere backend, base de datos y autenticación del lado del servidor.
